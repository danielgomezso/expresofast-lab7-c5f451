# ExpresoFast Frontend

Cliente Angular Standalone del laboratorio 10. La guía completa de base de datos, backend, usuarios y entregables está en [README principal](../README.md).

```powershell
npm ci
npx ng serve
```

Abrir http://localhost:4200 e iniciar sesión con un usuario del backend. Las rutas son /envios, /nuevo-envio y /rastreo. El servidor debe estar disponible en http://localhost:8080.

```powershell
npm run build
npm test -- --watch=false
```
